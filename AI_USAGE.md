# AI Usage Statement

This project used AI coding assistants to accelerate implementation, review,
and documentation. AI tools helped draft benchmark harness code, model wrapper
interfaces, test cases, README text, and report structure.

The team checked AI-assisted work by reading generated code, running unit tests
where dependencies were available, adding leakage checks around forecast timing,
and comparing implementation choices against official model documentation for
Chronos, TimesFM, and MOIRAI/Uni2TS. AI-generated text and code were treated as
draft material, not as source truth.

AI tools did not provide the underlying WRDS, CRSP, Compustat, Fama-French, or
TAQ data. Final empirical claims should be based only on committed benchmark
outputs generated by the reproduction pipeline.
